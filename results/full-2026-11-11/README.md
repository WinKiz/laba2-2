# Прерванная первая попытка полного эксперимента

Эта папка сохраняет диагностические данные первой попытки через Main.benchmark. Она не является итоговой серией.

На корпусе 32 млн слов общий HashMap при 8 потоках завис во время первого основного измерения после трёх прогревов. Дамп diagnostics/hashmap-8-hang.txt показывает зацикливание работника внутри HashMap$TreeNode.split/resize и ожидание Future.get главным потоком. Процесс остановлен извне; время завершения для зависшего запуска не получено и не выдумывалось.

Все три размера затем исследуются заново с отдельной JVM на конфигурацию и внешним ограничением времени. Итоговая серия расположена в ../full-isolated-2026-11-11/. Её результаты не смешиваются с частичными измерениями этой папки. Код семи Java-анализаторов остаётся прежним.
