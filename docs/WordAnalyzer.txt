WordAnalyzer — интерфейс, который задаёт общий договор для анализаторов. Конкретные классы, реализующие этот интерфейс, должны предоставить метод analyze. Он принимает путь к каталогу и количество потоков, возвращает словарь частот и может передать исключения.

Поле NAMES хранит список названий анализаторов: final запрещает заменить ссылку, а List.of создаёт неизменяемый список.

Статический метод create принимает название и через switch выбирает, объект какого анализатора создать. Он возвращает ссылку на этот объект через общий тип WordAnalyzer. При неизвестном названии выбрасывается исключение.

Сам create подсчёт не запускает — для этого вызывается analyze.
