## Повторная проверка 4 ноября 2026

Повторно собраны все исходники --release 21 и выполнен SelfTest. Независимый пересчёт Python подтвердил эталон всех трёх корпусов; SHA-256 файлов совпали с манифестом. Для всех 129 конфигураций заново проверены медианы, ускорение, эффективность и число корректных запусков по 645 исходным строкам. Исправлены оформление таблицы итогового отчёта и инструкция запуска после скачивания; Java-алгоритмы и измерения не менялись.

Структура упрощена до 12 Java-файлов: 7 реализаций, WordAnalyzer (интерфейс и выбор варианта), TestDataGenerator, Main (обычный запуск и метод benchmark), AnalysisSupport (чтение, проверка и потоки), SelfTest. Измерения запускаются командой Main benchmark. Разные способы подсчёта остаются отдельными классами.

Оговорки: фактическая JVM 23, не 21; --release 21 ограничивает API и формат байткода. Корпуса меньше 32 млн слов из примера (это пример, не обязательный минимум). Два прогрева/три измерения — допустимая, но короткая серия; малые времена и фиксированный порядок дают чувствительность к JIT/кэшу/фону. Оптимум относится только к данной серии. SelfTest запускается вручную, это не JUnit-тест Maven. Таймаут зависшего небезопасного HashMap не реализован; исходные опыты завершились.
