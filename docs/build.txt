build.ps1 — короткий сценарий сборки через PowerShell без Maven. Это вспомогательный способ для установленного JDK, а не часть алгоритма подсчёта.

ErrorActionPreference = Stop переводит ошибки командлетов в останавливающий сценарий режим. Set-Location $PSScriptRoot переходит в каталог, где находится сам сценарий, чтобы относительные пути работали из этой папки.

New-Item создаёт target/classes, если каталога ещё нет. Out-Null скрывает служебный вывод создания папки. Get-ChildItem рекурсивно находит все Java-файлы в src/main/java, ForEach-Object берёт полные пути, а @() собирает массив аргументов.

Оператор & вызывает javac. --release 21 задаёт совместимость с Java 21, -encoding UTF-8 — кодировку исходников, -d target/classes — папку результата, затем передаются найденные исходники. Если LASTEXITCODE не равен нулю, сценарий выбрасывает ошибку Compilation failed.

Этот файл только компилирует: он не генерирует корпус, не запускает Main, не проверяет эталон и не рисует графики. Готовые классы попадают в target, который исключён из Git.
