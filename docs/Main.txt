Main — точка входа программы. Метод main смотрит на аргументы и выбирает один из трёх режимов: демонстрация без параметров, обычный запуск одного варианта или серия benchmark.

Если args.length равен нулю, вызывается demo и затем return завершает main. Это режим кнопки Run в IDE. demo использует generated-data/ide-demo относительно рабочего каталога. Если каталога ещё нет, вызывается генератор: 128 файлов по 1000 слов, словарь 500. Существующий корпус не перезаписывается.

После загрузки эталона demo перебирает WordAnalyzer.NAMES. Для sequential назначается один поток, для остальных — от двух до четырёх. Каждый вариант создаётся через WordAnalyzer.create, выполняется, проверяется и печатается с названием, временем и OK либо MISMATCH. Намеренно ошибочные варианты могут дать несовпадение; случайное OK не доказывает их безопасность. Это одиночные демонстрационные запуски без прогрева, не полноценный эксперимент.

Если первый аргумент benchmark, main убирает его через Arrays.copyOfRange и передаёт остальные аргументы методу benchmark. В обычном режиме требуются три аргумента: каталог, количество потоков, название реализации. Эталон загружается до таймера. Создаётся анализатор, измеряется только вызов analyze, затем результат сравнивается с эталоном и печатается. При несовпадении обычный режим завершает процесс кодом 2.

Время измеряется разностью System.nanoTime. Деление на 1_000_000_000.0 даёт секунды без целочисленного усечения. В analyze входят чтение, нормализация, создание и завершение пула, подсчёт, объединение и преобразование результата. Проверка, генерация и печать вне таймера.

Метод benchmark принимает каталог данных, каталог результатов, число прогревов, число измерений и список потоков через запятую. Он проверяет параметры, загружает эталон и сохраняет сведения о среде. Перебираются все варианты, для sequential только один поток, для остальных заданный список.

Внутренний цикл сначала выполняет отрицательные номера прогревов, затем основные измерения. Каждый вызов analyze создаёт свежие счётчики. Проверяется результат каждого запуска, включая прогревы. Ошибки IOException и RuntimeException сохраняются как ERROR, несовпадения — как MISMATCH. InterruptedException не маскируется этой обработкой и может прервать серию.

В measurements.csv сохраняются вариант, число потоков, фаза, номер, время, корректность и описание. Запись CSV находится за пределами измерения. Сам Main не вычисляет медианы и не рисует графики: после серии этим занимаются report.py и plots.ps1. Поэтому для защиты нужно различать быстрый demo, одиночный запуск и полноценную серию измерений.
