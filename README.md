# Лабораторная №2: многопоточный анализ текста

Готовая работа: семь реализаций, независимый эталон генератора, тесты, реальные измерения на трёх корпусах, таблицы и графики. Начните с **docs/ЗАЩИТА.md**, затем **docs/ПОСТРОЧНО.md**. Отчёт: **results/conclusions.md**, все вопросы 1–11 разобраны также в отчёте. Проверка пунктов: **docs/ЧЕКЛИСТ.md**.

## Запуск в NetBeans одной кнопкой

1. Клонируйте `https://github.com/WinKiz/laba2-2.git`.
2. В NetBeans выберите **File → Open Project** и папку клона с `pom.xml` (не папку `src`). Это готовый Maven-проект, новый проект создавать не нужно.
3. В **Project Properties → Build → Compile** проверьте Java Platform: **JDK 21 или новее**. Для Maven также нужен JDK 21+; JDK 8/17 не скомпилирует проект.
4. Откройте `Source Packages → ru.student.lab2 → Main.java`, выберите **Run File** (обычно Shift+F6). Также можно **Run Project** (F6): главный класс задан свойством `exec.mainClass` в pom.xml. Если IDE спросит, выберите `ru.student.lab2.Main`. Аргументы оставьте пустыми.
5. Результаты появятся в **Output**: семь строк с названием алгоритма, числом потоков, временем и `OK` / `MISMATCH`.

При первом запуске без аргументов Main сам создаёт небольшой корпус `generated-data/ide-demo` (128000 слов). При следующих запусках использует его повторно. У двух намеренно неправильных вариантов (`hashmap`, `concurrent-get-put`) возможен `MISMATCH` — это демонстрация гонки, не ошибка установки. У корректных вариантов должен быть `OK`.

Это демонстрационный запуск без прогрева, не полный эксперимент и не построение графиков. Итоговые графики уже находятся в results/. Серия измерений запускается отдельно через `Main benchmark ...`. Если задать три аргумента, сохраняется прежний запуск одного варианта. Если папка ide-demo повреждена/неполна, используйте новый каталог через обычный запуск с аргументами или удалите только этот демонстрационный корпус и запустите снова.

При первом открытии нужен интернет для загрузки Maven-плагинов. Названия пунктов меню могут немного отличаться по версии NetBeans. Стандартный запуск Java/Maven описан в официальной документации: https://netbeans.apache.org/tutorial/main/kb/docs/java/quickstart/ .

## Сборка и проверка

Требуется JDK 21 или новее. Генератор запускайте один раз: повторный запуск в непустой каталог намеренно запрещён. Выполнить PowerShell в папке проекта:

```powershell
.\build.ps1
java -cp target/classes ru.student.lab2.SelfTest
java -cp target/classes ru.student.lab2.TestDataGenerator generated-data/demo 128 10000 500
java -cp target/classes ru.student.lab2.Main generated-data/demo 4 concurrent-merge
```

Альтернатива при установленном Maven: `mvn compile`. Первоначально сборка проверена javac --release 21 на JDK 23.0.2. Дополнительно 4 ноября проверены Maven 3.9.9 (временная копия без установки в систему), compile и exec:java, а также чистый локальный клон без данных и готовых классов. Совместимость исходников/API и байткода с 21 проверяется компилятором; запуск непосредственно на JVM 21 не проверялся.

## Варианты

`sequential`, `hashmap`, `synchronized-map`, `concurrent-get-put`, `concurrent-merge`, `long-adder`, `local-maps`.

Main принимает **каталог, потоки, вариант** именно в этом порядке. Для sequential только 1. Код завершения 2 означает несовпадение с эталоном, остальные ошибки параметров/чтения не скрываются.

## Новые данные и повтор эксперимента

```powershell
java -cp target/classes ru.student.lab2.TestDataGenerator generated-data/new 128 10000 500
java -Xms256m -Xmx1g -cp target/classes ru.student.lab2.Main benchmark generated-data/new results/new 2 3 1,2,4,8,16,32,64
```

Этот пример сохраняет новую серию в `results/new`. `report.py` строит сводный отчёт только для сохранённой тройки `small/medium/large`, поэтому результаты `new` автоматически не включаются. Для повторной обработки исходной тройки при наличии соответствующих корпусов выполните `python report.py`, затем `.\plots.ps1`.

Параметры генератора: каталог, файлов, слов на файл, размер словаря, необязательный seed. Без seed каждый запуск получает новое случайное начальное состояние. С сохранённым seed можно повторить корпус; параметры и seed находятся в metadata.txt и results/corpora.md. Непустой каталог защищён от перезаписи. Полный рекомендуемый размер из примера: `128 250000 500` (32 млн слов); в сданном эксперименте уменьшены размеры для разумного времени, число файлов и весь диапазон потоков сохранены.

`report.py` обрабатывает папки small/medium/large; графики PNG создаёт `plots.ps1`, SVG строятся стандартным Python без библиотек. Не запускайте сборку/тесты/другие тяжёлые задачи одновременно с измерениями. Один анализатор за раз, 2 прогрева + 3 измерения каждой пары, медиана. Если нужна более устойчивая оценка, увеличьте до 3 и 5. Время включает открытие/чтение файлов, нормализацию, создание/завершение пула, подсчёт, объединение и преобразование результата. Эталон, сравнение, CSV и консоль за пределами таймера. Это учебный эксперимент с файловым кэшем ОС, не JMH и не измерение холодного диска.

Обрабатываются только обычные файлы `text-[цифры].txt` непосредственно в указанном каталоге. Служебные файлы не являются входным текстом. UTF-8; слово — непустая последовательность Unicode-букв/цифр. Пунктуация разделяет слова; регистр снижается через Locale.ROOT. Для генератора это точно соответствует условию. Варианты с Integer рассчитаны на счётчики до 2 147 483 647; корректные merge используют Math.addExact и явно сообщают переполнение. Перевод результата в Long после подсчёта не расширяет предел исходного Integer.

## Ограничения

Общий HashMap и concurrent-get-put намеренно некорректны. Их успешный запуск не доказывает безопасность. Ошибки работников попадают в CSV; для ошибочных запусков числовое время нельзя интерпретировать как время корректного подсчёта. При произвольном повреждении HashMap теоретически возможно зависание; для таких опытов лучше отдельная JVM с внешним таймаутом. В этой серии зависаний не наблюдалось.

## Краткая структура (12 Java-файлов)

- 7 файлов анализаторов — по одному на каждый вариант из задания.
- `WordAnalyzer.java` — интерфейс, список вариантов и их создание.
- `TestDataGenerator.java` — генерация данных и независимого эталона.
- `Main.java` — один запуск и отдельный метод `benchmark` для серии измерений.
- `AnalysisSupport.java` — общие методы чтения, проверки результата и работы с потоками.
- `SelfTest.java` — проверочные примеры.

Пример серии: `java -cp target/classes ru.student.lab2.Main benchmark generated-data/large results/new 2 3 1,2,4,8,16,32,64`. Это заменяет прежнюю точку входа Benchmark. Существующие таблицы получены до объединения служебных классов; формулы, алгоритмы и правила обработки сохранены. Проверочный запуск новой структуры не подменяет исходные экспериментальные данные.

Сам интерфейс NetBeans не проверялся: IDE в среде не установлена. Проверены стандартная Maven-сборка и выполнение Main, используемые для запуска из IDE.
